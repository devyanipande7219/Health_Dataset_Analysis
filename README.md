# 🏥 Healthcare Dataset Analysis (SQL Project)

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** using SQL on a healthcare dataset. The goal is to extract meaningful insights related to patients, doctors, appointments, billing, and prescriptions by performing structured queries on multiple relational tables.

The project demonstrates strong SQL skills including **data cleaning, aggregation, filtering, joins, and business-driven analysis**.

---

## 🗂️ Dataset Description

The project uses **5 CSV tables**, which were imported into a SQL database:

* **patients** → Contains patient details (ID, name, age, gender, etc.)
* **appointments** → Information about patient appointments with doctors
* **doctors** → Doctor details and specialization
* **billings** → Billing amount, payment status, and transaction details
* **prescriptions** → Medicines prescribed and treatment information

---

* SQL (MySQL / SQL Workbench)

## 🔍 Key Analysis Performed

### 1. Patient Analysis

* Total number of patients
* Gender distribution
* Age-based segmentation

### 2. Appointment Insights

* Total appointments per doctor
* Most active doctors
* Appointment trends

### 3. Doctor Performance

* Number of patients handled by each doctor
* Specialization-wise analysis

### 4. Billing Analysis 💰

* Total revenue generated
* Paid vs unpaid bills
* Highest billing departments

### 5. Prescription Analysis 💊

* Most prescribed medicines
* Treatment patterns
